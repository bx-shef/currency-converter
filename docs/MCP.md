# Инструменты для AI-агента shef.cowork (MCP)

> Last reviewed: 2026-11-24

Конвертер отдаёт AI-агенту shef.cowork четыре инструмента: агент отвечает на «сколько 5 000 USD в BYN по курсу на
вчера» и «напиши сумму прописью» официальным курсом НБ РБ, а не курсом из интернета. Задача — issue #200, кейс —
bx-shef/toolsai `docs/private/cases/31-konverter-valyut.md`.

Протокол облачных приложений shef.cowork — bx-shef/toolsai-mcp `docs/CLOUD_APPS.md`, публичная копия —

`docs/MCP.md`).

## Инструменты

Все — только чтение, без данных портала и без токенов портала. Успех — JSON для модели с полем `say` (как
пересказать); отказ — текст с `isError` и кодом в `_meta.code`.

| Имя | Что | Аргументы |
|---|---|---|
| `rates` | официальные курсы на дату: BYN за `scale` единиц валюты | `date` (ГГГГ-ММ-ДД, нет — сегодня по Минску), `codes` (до 20; нет — USD, EUR, RUB, CNY, KZT, PLN) |
| `history` | курс одной валюты по дням за период: точки с масштабом, изменение, минимум и максимум за единицу | `code`, `from` (обязательно), `to` (нет — сегодня); до 366 дней |
| `convert` | пересчёт суммы через BYN по курсу на дату: итог, курсы, дата | `amount` (0 … 10¹²), `from`, `to`, `date` |
| `sum_in_words` | сумма прописью для BYN и RUB, как в платёжке: «Сто двадцать три рубля 45 копеек» | `amount`, `currency` (`BYN`, `RUB`) |

У `rates`, `history` и `convert` в описании: «курсы портала — встроенным инструментом курсов портала (`crm_currency`);
официальный курс НБ РБ — этим; в интернете не искать».

### Коды отказов

| Код | Когда |
|---|---|
| `bad_args` | неверный аргумент: код валюты, дата не ГГГГ-ММ-ДД или несуществующая, дата раньше 01.07.2016 или позже завтрашней, период длиннее 366 дней, сумма вне 0 … 10¹², итог не помещается в точные копейки, валюта без официального курса |
| `not_published` | курс на эту дату НБ РБ ещё не установил (на завтра — публикуется днём) |
| `rates_unavailable` | НБ РБ не ответил или не ответил месячный фид для валюты с месячным курсом; временная ошибка, курс не подставляется |
| `unknown_tool` | нет такого инструмента |

## Правила расчётов

- **Курсы — только с 01.07.2016.** Раньше НБ РБ публиковал курсы в старых рублях (BYR, 10 000 BYR = 1 BYN); выдать
  их как BYN — ошибка в 10 000 раз («100 USD = 1 489 000 BYN»).
- Курс — дневной фид НБ РБ; валюты, которые НБ РБ устанавливает только помесячно (RSD), — из месячного
  (`periodicity: monthly`). Не ответил месячный фид — такая валюта получает `rates_unavailable`, а не «нет курса»,
  и неполный результат не кешируется.
- **История склеивается по всем идентификаторам валюты.** У НБ РБ `Cur_ID` меняется (09.07.2021 — у всех валют,
  01.07.2016 — у части, KZT ещё и с масштабом 1 → 1000). Отрезки берутся из `/currencies` по общему `Cur_ParentID`,
  каждый со своим масштабом; изменение, минимум и максимум считаются за единицу валюты (`bynPerUnit`). Первая точка
  позже начала периода, обрыв в конце, месячная валюта и смена периодичности внутри периода — оговорка в `say`.
  Справочник `/currencies` хранится 6 часов.
- Пустой месячный фид (на 1-е число месячный курс может выйти позже дневного) — то же, что сбой: `rates_unavailable`.
- Копейки округляются только через `toKopecks` (`app/utils/formatters.ts`); `convert` идёт тем же путём, что экран
  конвертера (`convert` → сетка 4 знака → `toKopecks`), поэтому сайт и агент сходятся до копейки. Итог больше 2⁵³ копеек — отказ, а не тихое округление; на суммах
  от ~10¹³ копейка ограничена точностью чисел с плавающей точкой (так же, как на экране).
- Даты — по Минску (UTC+3). На выходной НБ РБ отдаёт курс последнего рабочего дня под запрошенной датой — показываем
  запрошенную.
- Кеш в памяти процесса: прошедшая дата — 24 часа, сегодня и завтра — 30 минут; одновременные запросы одной даты
  идут к НБ РБ одним запросом; сбой не кешируется.

## Ключ подключения — по порталу, а не по `member_id`

`member_id` не уникален среди всех Битрикс24: коробки, развёрнутые из одного образа, могут его совпадать
(bx-shef/toolsai-mcp #243). Поэтому ключ хранится по паре **`member_id` + хост портала** (`mcpkey:<member_id>:<хост>`;
хост — punycode, нижний регистр, без порта и точки в конце; `www.` сохраняется: `company.by` и `www.company.by` —
разные порталы). Выпуск или отзыв ключа на одном портале не трогает другой.

На один `member_id` — до 8 порталов. Когда места нет, новому порталу уступает место тот, чей ключ не подписал ни
одного запроса 30 дней; если все работали — отказ с текстом «отзовите ключ на неиспользуемой копии».

Протокол передаёт в заголовке только `X-Shef-Member`, поэтому запрос проверяется каждым ключом этого `member_id` за
постоянное время (без досрочного выхода); подошедший ключ даёт хост, и `who.host` из подписанного тела обязан с ним
совпасть. Заголовок с хостом в протоколе — bx-shef/toolsai-mcp #304.

Ключ зашифрован AES-256-GCM (ключ — HKDF от `ENCRYPTION_KEY`), внутри шифротекста — `member_id` и хост: запись,
перенесённая под имя другого портала, не читается.

## Проверка запроса

1. Тело больше 64 КБ — `413` (до любой работы с ключами).
2. Ключи по `X-Shef-Member`; нет ни одного — `401`.
3. `HMAC-SHA256(ключ, ts + "." + сырое тело)` против `X-Shef-Signature`, каждым ключом; не подошёл ни один — `401`.
4. `|сейчас − ts| ≤ 300` — иначе `401`.
5. Тело: битый JSON или нет `tool`, `nonce`, `who` — `400`; `ts` и `who.member_id` не равны заголовкам или `who.host`
   не равен хосту ключа — `401`.
6. `nonce` встречался за 601 секунду — `409` (запрос, подписанный на 300 с вперёд, ещё годен через 600 с — номер
   должен пережить эту секунду). Запись атомарна: в Redis — `SET NX EX`.

Причина отказа (`unknown_member`, `bad_signature`, `host_mismatch`…) — только для журнала сервера: маршрут отвечает
на все `401` одинаково. Контрольные значения подписи протокола сверяет `tests/mcpProtocol.test.ts`.

## Проверено

- Мутациями (каждая краснит тесты): ключ только по `member_id`, без сверки хоста, без окна времени, без одноразового
  номера, запись не привязана к хосту, копейки в обход `toKopecks`, курс на будущую дату.
- На живом api.nbrb.by (24.11.2026): 5 000 USD = 14 971,50 BYN на 20.11.2026; курс на 2015 год — отказ «BYR»; история
  USD через смену `Cur_ID` 09.07.2021 — без пропуска; KZT — масштаб 1000; RSD внутри месяца — пусто с пояснением.
